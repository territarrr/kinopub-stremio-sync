# kinopub-stremio-sync

Две независимые штуки для [Stremio](https://www.stremio.com/), работающие бесплатно на Cloudflare Workers:

1. **Синхронизация с кинопабом.** Переносит «Я смотрю», недосмотренные фильмы и закладки кинопаба в библиотеку Stremio, а потом раз в 5 минут синхронизирует в обе стороны отметки «просмотрено» и место, где вы остановились.
2. **Полка «Я смотрю» для Stremio.** Аддон-каталог на главном экране: сериалы из вашей библиотеки Stremio, у которых есть вышедшие непросмотренные серии, с их числом прямо на постере. Работает только с данными Stremio, кинопаб для неё не нужен. Один развёрнутый экземпляр может обслуживать любое число аккаунтов Stremio: у каждого своя ссылка со страницы настройки.

На телевизор и телефон ничего ставить не надо: всё живёт в облаке, а приложения Stremio берут данные из аккаунта.

> Используются неофициальные API Stremio и кинопаба. Они могут измениться без предупреждения. Проект никак не связан ни со Stremio, ни с кинопабом.

## Как это работает

### Синхронизация (`src/worker.ts`, `src/sync.ts`)

- **Кинопаб**: API `api.srvkp.com/v1` ([документация](https://kinoapi.com)), вход через OAuth device flow (код на `kino.pub/device`). Своих `client_id`/`client_secret` кинопаб выдаёт по запросу в поддержку. Здесь используются публичные данные из открытого [Kodi-аддона](https://github.com/quarckster/kodi.kino.pub). Если получите свои, замените их в `src/kinopub.ts`.
- **Stremio**: тот же API (`api.strem.io/api/datastoreGet|datastorePut`), через который приложения синхронизируют библиотеку. Просмотренные серии хранятся в виде битового поля. Его формат перенесён из [stremio-core](https://github.com/Stremio/stremio-core/tree/development/stremio-watched-bitfield) (`src/bitfield.ts`). Список серий берётся из Cinemeta.
- Фильмы и сериалы сопоставляются по IMDb ID, серии — по номеру сезона и серии.
- **Отметки «просмотрено»** сливаются трёхсторонним слиянием относительно последнего согласованного состояния, поэтому снятие отметки тоже переносится. Если одну серию на одной стороне отметили, а на другой сняли отметку, побеждает отметка. Если с одной стороны разом пропало больше трёх отметок, это считается сбоем и игнорируется.
- **Место в серии**: побеждает более свежий просмотр.
- **Что считается изменившимся**: история кинопаба, счётчики «Я смотрю» и `_mtime` элементов библиотеки Stremio. Новые сериалы из «Я смотрю», истории и закладок (закладки проверяются раз в час) сами добавляются в Stremio. В обратную сторону сериалы не добавляются.
- На бесплатном тарифе Cloudflare у одного запуска есть лимит в 50 исходящих запросов. Если изменений больше, остаток доделывается в следующем запуске.
- Страница состояния `/status?key=…` показывает журнал изменений и ошибок, отметку о последнем автоматическом запуске и кнопку «Синхронизировать сейчас».

### Полка «Я смотрю» (`src/shelf-worker.ts`, `src/shelf.ts`, `src/badge.ts`)

- Берёт библиотеку Stremio и считает для каждого сериала вышедшие серии обычных сезонов, которые не отмечены просмотренными.
- Списки серий с датами выхода кешируются в KV и обновляются из Cinemeta раз в 6 часов. Поэтому в день выхода серии счётчик растёт сам.
- Начатые сериалы стоят сверху: сначала со свежими сериями или недавно смотренные. Не начатые идут ниже с подписью «не начат».
- На постерах начатых сериалов нарисован значок с числом (векторные цифры, растеризация с антиалиасингом, `jpeg-js`). Картинка рисуется один раз на каждое значение и хранится в KV. Постеры, которые Cinemeta отдаёт только в WebP, сначала конвертируются через публичный прокси [wsrv.nl](https://wsrv.nl).
- Отрисовка постера заметно превышает формальный лимит CPU бесплатного тарифа (10 мс). Сейчас Cloudflare это допускает. Если начнёт запрещать, верните в `shelf.ts` обычный `posterUrl(...)`: число останется в названии.

## Установка

Нужны Node.js 23.6+ (TypeScript запускается напрямую), бесплатный аккаунт Cloudflare и аккаунт Stremio. Для синхронизации ещё подписка на кинопаб.

```sh
npm install
npx wrangler login
```

### 1. Входы и разовый перенос (локально)

```sh
cp .env.example .env              # впишите почту и пароль Stremio
npm run cli stremio-login         # пароль остаётся в .env, в state.json кладётся только authKey
npm run cli kp-login              # покажет код для kino.pub/device
npm run cli -- import --dry-run   # что будет перенесено, ничего не записывает
npm run cli import                # записать в библиотеку Stremio
```

Если сериал уже есть в библиотеке Stremio, отметки объединяются, ничего не теряется. Серии, которые не удалось сопоставить (разная нумерация), выводятся в отчёте.

### 2. Облако

Создайте два KV-хранилища и подставьте их id в локальные копии конфигов:

```sh
npx wrangler kv namespace create STATE
npx wrangler kv namespace create SHELF
cp wrangler.toml wrangler.local.toml              # id от STATE
cp wrangler.shelf.toml wrangler.shelf.local.toml  # id от SHELF
```

Секретные ключи для адресов (любая случайная строка, например `openssl rand -hex 12`):

```sh
npx wrangler secret put STATUS_KEY -c wrangler.local.toml
npx wrangler secret put SHELF_KEY  -c wrangler.shelf.local.toml
```

Перенести входы в облако и выложить:

```sh
npm run upload-state     # после этого токены кинопаба есть только в облаке
npm run deploy:sync
npm run deploy:shelf
```

После `upload-state` не запускайте синхронизацию с компьютера. Кинопаб при обновлении выдаёт новый refresh-токен и отменяет старый, поэтому облако и компьютер выбивали бы друг друга.

Если `wrangler deploy` просит зарегистрировать поддомен `workers.dev`, откройте в панели Cloudflare раздел Workers & Pages: поддомен создастся сам.

### 3. Установить полку в Stremio

Откройте `https://stremio-watching-shelf.<ваш-поддомен>.workers.dev/`, подтвердите вход на официальной странице `link.stremio.com` (тот же способ, что и вход на телевизоре: ссылка, QR-код или код) и нажмите «Установить в Stremio»: страница сама добавит аддон в аккаунт первым в списке (через `addonCollectionGet/Set` прямо из браузера), поэтому полка окажется на самом верху главной. Запасной вариант — вставить выданную ссылку в поиск в разделе «Аддоны» (тогда аддон встанет в конец, его можно перетащить). Этой страницей могут пользоваться другие люди: каждый получает свою ссылку.

Как это устроено: аддоны Stremio не знают, какой аккаунт их открыл, поэтому ключ доступа (`authKey`) зашит в адрес — `/u/<base64url(authKey)>/manifest.json`. Пароль на странице не вводится вообще, а ключ браузер получает напрямую от `link.stremio.com` и сам собирает ссылку — во время настройки через Worker не проходит ни пароль, ни ключ. Ключ даёт доступ к аккаунту, так что личной ссылкой не стоит делиться; выход из Stremio на всех устройствах делает ключ недействительным.

Владелец может также пользоваться адресом `/<SHELF_KEY>/manifest.json` — тогда ключ берётся из KV (`npm run upload-state -- --shelf`).

Полки на главной идут в порядке аддонов: перетащите «Я смотрю» наверх списка. Аддон синхронизируется через аккаунт, на телевизоре он появится после перезапуска Stremio.

### Только полка, без кинопаба

Достаточно создать `SHELF`, задать `SHELF_KEY` и выполнить `npm run deploy:shelf`, а дальше установить полку через страницу настройки.

## Ограничения

- **Прогресс.** В Stremio прогресс хранится только для одной серии сериала (текущей), в кинопабе — для каждой. Переносится позиция в последней начатой серии.
- **Нумерация.** У кинопаба и IMDb/Cinemeta иногда разная нумерация (спецвыпуски, объединённые серии). Такие серии не переносятся и попадают в отчёт.
- **Невидимые сериалы.** `watching/serials?subscribed=1` отдаёт только сериалы с непросмотренными сериями. Остальные из «Я смотрю» находятся по истории просмотров. Сериал, добавленный в «Я смотрю», из которого не посмотрено ни одной серии и у которого ещё нет вышедших серий, не найдётся, пока не выйдет первая.
- **Папки закладок.** В Stremio нет папок, все закладки попадают в общую библиотеку.
- **Удаление из библиотеки.** Если удалить сериал из библиотеки Stremio, синхронизация не вернёт его обратно.
- **Срок входа в кинопаб.** Refresh-токен живёт 30 дней и продлевается при каждом обновлении. Если синхронизация не работала дольше, нужно снова выполнить `kp-login` и `upload-state`.

## Структура

| Файл | Что делает |
| --- | --- |
| `src/kinopub.ts` | клиент API кинопаба, OAuth device flow, обновление токенов |
| `src/stremio.ts` | вход и библиотека Stremio, Cinemeta |
| `src/bitfield.ts` | формат «просмотренных серий» Stremio (порт из stremio-core) |
| `src/model.ts` | общее представление состояния просмотра и преобразования |
| `src/migrate.ts` | разовый перенос |
| `src/sync.ts` | двусторонняя синхронизация |
| `src/worker.ts` | Worker синхронизации: cron и страница состояния |
| `src/shelf.ts`, `src/shelf-worker.ts`, `src/shelf-page.ts` | аддон-полка «Я смотрю» и страница настройки |
| `src/badge.ts` | значок с числом на постере |
| `src/cli.ts` | локальные команды |
| `scripts/upload-state.ts` | перенос входов и состояния в KV |
